3. Năm đặc tính NIST

1. On-demand Self-service

Sinh viên tự tạo Codespace qua GitHub mà không cần người quản trị cấp máy thủ công.

2. Broad Network Access

API chạy trên Codespaces và được truy cập từ điện thoại thông qua URL HTTPS công khai.

3. Resource Pooling

GitHub cấp tài nguyên tính toán từ hạ tầng đám mây dùng chung. Sinh viên không cần quản lý máy chủ vật lý.

4. Rapid Elasticity

Codespaces cho phép lựa chọn cấu hình máy và cấp phát thêm môi trường khi cần. Bài thực hành đã tạo máy 2-core; chưa thử trực tiếp việc tăng cấu hình.

5. Measured Service

GitHub Billing Usage ghi nhận thời gian tính toán, loại máy, dung lượng lưu trữ và chi phí sử dụng.

4. Kết luận

Qua bài thực hành, em đã tạo môi trường lập trình trên đám mây, xây dựng API Hello Cloud bằng Node.js và Express, chạy ứng dụng qua Internet và theo dõi việc sử dụng tài nguyên.

GitHub Codespaces giúp giảm thời gian cài đặt và đồng bộ môi trường giữa các thiết bị. Tuy nhiên, việc sử dụng phụ thuộc vào kết nối Internet và hạn mức tài nguyên của nhà cung cấp.
